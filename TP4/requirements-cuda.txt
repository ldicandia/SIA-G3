# Extra OPCIONAL para correr los cálculos de arrays en la GPU (backend "cupy").
# No hace falta para ningún test ni para ninguna corrida: el backend por defecto es numpy.
#
# La RTX 5070 (Blackwell) necesita un driver de NVIDIA que exponga CUDA 12.8 o superior
# dentro de WSL; verificalo con `nvidia-smi` antes de instalar.
#
# Instalación (manual, desde el directorio TP4/):
#   .venv/bin/pip install -r requirements-cuda.txt
#
# Ante cualquier falla (cupy ausente, sin dispositivo CUDA, driver incompatible) tp4 vuelve a
# numpy, emite un RuntimeWarning y deja el motivo en run.json (backend.fallback_reason).
#
# El extra [ctk] trae las librerías de runtime de CUDA (cuBLAS, NVRTC, cuSOLVER...) como wheels
# oficiales de NVIDIA (nvidia-*-cu12) desde PyPI. Sin él, cupy importa y ve la GPU pero falla en
# la primera operación (por ejemplo `@`) si no hay un CUDA Toolkit 12.x instalado en el sistema.
-r requirements.txt
cupy-cuda12x[ctk]>=13.4
